# Bucket 2 — official form pre-fill: BLOCKED on a real source PDF

**Status: stub.** `mappings/pt-d8-national-visa-form.mapping.ts` and
`assets/pt-d8-national-visa-form.STUB.pdf` are placeholders, not the real
Portuguese national visa application form ("Formulário de Pedido de Visto
Nacional").

## Why

No copy of the official form was available anywhere in this build
environment. Two files that looked promising in a sibling project
directory (`form.pdf`, `form_overlayed.pdf`) were checked and turned out to
be an unrelated Indian health-insurance claim form containing someone's
personal data — not the Portuguese visa form. Per the build instructions,
we do not fabricate field names pretending to be sourced from the
Portuguese government.

## What exists instead

- `assets/pt-d8-national-visa-form.STUB.pdf` — a self-authored, obviously
  fake fillable PDF (generated by `scripts/generate-stub-pdf.ts`) with a
  bright red "SAMPLE / PLACEHOLDER — NOT THE OFFICIAL FORM" banner baked
  into page 1, and field names like `stub_full_name`.
- `mappings/pt-d8-national-visa-form.mapping.ts` — maps those stub field
  names to questionnaire answers, with `isStub: true`.
- `fill.ts` — generic filler that works identically for a stub or a real
  mapping.
- The checklist UI shows a "Preview only — sample form, not final" badge
  on this document, driven by `isStub`.

## What must happen before launch

1. Obtain the real official PDF from a Portuguese consulate, VFS Global, or
   AIMA source.
2. Inspect its actual AcroForm field names (`pdfDoc.getForm().getFields()`
   in pdf-lib) — or, if it isn't a fillable form, its coordinate layout.
3. Replace `assets/pt-d8-national-visa-form.STUB.pdf` with the real file
   and rewrite `mappings/pt-d8-national-visa-form.mapping.ts` field-by-field.
4. Flip `isStub` to `false`.
5. Re-run `prisma/seed.ts` (or a targeted update) so the `CountryConfig` row
   for `formFill.nationalVisaForm.fieldMapping` picks up a real `sourceUrl`
   and today's `effectiveFrom`.

No changes to `fill.ts`, `document-engine/generate.ts`, or any UI component
should be required for this swap — if they are, something got hardcoded
that shouldn't have been.
